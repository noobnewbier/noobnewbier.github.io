This is an experiment project primarily created for experiment, where I play with ideas such as custom editor tooling and try out new technology.

So far, I have built a few tools to help me build a game, some of which include:
- Embedded scene editor for level editing
- Value Tracker that work innately with Unity's profiler.
- Command Console
- Auto complete support
- Various custom inspector helper for easier animation editing
- (I have also made some pixelation shader and proper cel shading is on its way!)

The project is for prototyping purposes and serves no commercial value. However it should serve a demo to my interest and ability.
