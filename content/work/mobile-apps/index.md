I was involved in 18 different Android apps
when I was working for [InCrowd Sports](https://www.incrowdsports.com/). Some of the more significant work includes premium user authentication for videos in [Crystal Palace FC](https://play.google.com/store/apps/details?id=uk.co.tribehive.fli.palace)
and releasing [Guinness PRO14](https://play.google.com/store/apps/details?id=org.pro14rugby.app).

The sheer amount of clients we were dealing with simultaneously and the new contracts the company is making introduced various challenges
to maintaining a healthy code base and keeping up with the latest technology.
I am proud to be part of the team that overcome these problems through joint effort across different disciplines.

I have hence developed strong UI programming skills and am reasonably familiar with Android development.

Highlights:
- Creating a reliable and testable front end for commercial purposes
- Work across various codebase and create reusable libraries.
- Strong UI background and can provide insights from a mobile developer perspective.
- Also assisted in creating a continuous integration environment for other developers.
